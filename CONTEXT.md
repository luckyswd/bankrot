# CONTEXT.md — глоссарий

Словарь предметной области и сопоставление юридических терминов с
идентификаторами в коде. Читать вместе с @CLAUDE.md.

Предметная область — **банкротство физических лиц в РФ** (ФЗ № 127-ФЗ
«О несостоятельности (банкротстве)»). Пользователи системы — юристы, которые
ведут дела должников и готовят документы для арбитражного суда.

---

## Главная ловушка именования

| В коде | Что это на самом деле |
|---|---|
| `Contracts` (`contracts`) | **Дело о банкротстве целиком**, карточка клиента. Не «договор». Номер и дата договора с клиентом — всего лишь поля `contractNumber` и `contractDate` внутри неё. Сущность названа во множественном числе, но описывает один объект. |
| `ClientCard` (фронтенд) | Экран одного `Contracts`. Маршрут `/contract/:id`. |
| `Dashboard` (фронтенд) | Список дел, маршрут `/contracts`. |
| `databases` / «Базы» | Справочники (`Court`, `Creditor`, ...), а не базы данных. |

---

## Стадии процедуры

Enum `BankruptcyStage`. Одновременно стадия дела, группа сериализации и
категория шаблона документа.

| Значение | Название в интерфейсе | Смысл |
|---|---|---|
| `basic_info` | Основная информация | Анкета должника: ФИО, паспорт, адрес, семья, работа, долги, договор с юристом. |
| `pre_court` | Досудебка | Подготовка к подаче заявления: доверенность, выбор суда, список кредиторов, публикация о намерении, номер дела. |
| `judicial_procedure_initiation` | Судебка, введение процедуры | Суд принял заявление и ввёл процедуру: определение/решение, назначен финуправляющий, рассылка запросов в госорганы, спецсчёт. |
| `judicial_procedure` | Судебка, процедура | Ход процедуры: требования кредиторов, формирование реестра, реализация имущества. |
| `judicial_report` | Судебка, отчёт | Итоговый отчёт финуправляющего и завершение процедуры. |

**Статус дела** — enum `ContractStatus`: `in_progress` («В работе»),
`completed` («Завершено»).

## Участники процедуры

| Термин | В коде | Пояснение |
|---|---|---|
| **Должник** | поля `Contracts` | Физлицо, в отношении которого ведётся банкротство. Отдельной сущности нет — данные лежат прямо в `Contracts`. |
| **Финансовый управляющий**, финуправляющий, ФУ | `FinancialManager` | Арбитражный управляющий, назначаемый судом для банкротства гражданина. Ведёт реестр, распоряжается имуществом, публикует сведения. |
| **Арбитражный управляющий**, АУ | `arbitrationManagerRegistryNumber` | Номер в сводном госреестре арбитражных управляющих. |
| **СРО АУ** / ААУ | `aauName`, `aauOgrn`, `aauInn`, `aauAddress` | Саморегулируемая организация (ассоциация) арбитражных управляющих, членом которой состоит ФУ. Её реквизиты указываются в судебных документах. |
| **Кредитор** | `Creditor` | Банк, МФО, ФНС или физлицо, которому должник должен деньги. Справочник. |
| **Суд** | `Court` | Арбитражный суд, рассматривающий дело. Справочник. |
| **Судья** | `procedureInitiationJudge` | ФИО судьи по делу. |
| **Автор дела** | `Contracts::$author` -> `User` | Юрист компании, ведущий дело. |

## Государственные органы (справочники запросов)

На стадии введения процедуры финуправляющий рассылает запросы об имуществе
должника. Каждый орган — отдельный справочник со своим CRUD и связью из
`Contracts`.

| Аббревиатура | В коде | Расшифровка и зачем нужен |
|---|---|---|
| **ФНС** | `Fns`, `procedureInitiationFns` | Федеральная налоговая служба. Сведения о доходах, счетах, статусе ИП, участии в юрлицах. |
| **МЧС** | `Mchs`, `procedureInitiationMchs` | ГИМС МЧС. Сведения о маломерных судах (лодки, катера). |
| **Росгвардия** | `Rosgvardia`, `procedureInitiationRosgvardia` | Сведения о зарегистрированном оружии. |
| **Гостехнадзор** | `Gostekhnadzor`, `procedureInitiationGostekhnadzor` | Сведения о самоходной технике (тракторы, снегоходы, квадроциклы). |
| **ФССП** / приставы | `Bailiff`, `procedureInitiationBailiff` | Федеральная служба судебных приставов, отдел судебных приставов (ОСП). Сведения об исполнительных производствах; при введении процедуры они прекращаются. |

## Ключевые понятия

| Термин | В коде | Пояснение |
|---|---|---|
| **ЕФРСБ** | `efrsbDateTime`, `efrsbCabinet` | Единый федеральный реестр сведений о банкротстве (fedresurs.ru). Обязательные публикации о введении процедуры, торгах, завершении. `efrsbCabinet` — зал/кабинет заседания, попадающий в текст публикации. |
| **Досудебка** | стадия `pre_court` | Всё, что делается до подачи заявления в суд. |
| **Определение суда** | `procedureInitiationDecisionDate` | Судебный акт о принятии заявления и введении процедуры. |
| **Решение суда** | `procedureInitiationResolutionDate` | Решение о признании гражданина банкротом. Наличие даты влияет на формулировку «резолютивной части» в документах. |
| **Реализация имущества** | стадия `judicial_procedure` | Основная процедура банкротства гражданина: имущество продаётся, деньги распределяются между кредиторами. |
| **Реестр требований кредиторов**, РТК | `ContractsCreditorsClaim` | Список признанных судом требований. Каждая запись — требование одного кредитора с разбивкой по суммам. |
| **Требование кредитора** | `ContractsCreditorsClaim` | Заявление кредитора о включении в реестр. Поле `inclusion` (несмотря на название) означает «требование получено». |
| **Основной долг** | `principalAmount` | Тело долга без процентов и санкций. |
| **Финансовые санкции** | `financialSanctions` | Штрафы, пени, неустойки одной суммой (в досудебном списке кредиторов). |
| **Проценты / штраф / пеня / неустойка** | `interest`, `penalty`, `lateFee`, `forfeiture` | Раздельные составляющие требования в реестре. |
| **Госпошлина** | `stateDuty`, `stateDutyForConsideration` | Уплаченная госпошлина и госпошлина за рассмотрение конкретного требования. |
| **Основания требования** | `basis` (JSON) | Массив документов-оснований с номером и датой (кредитные договоры, судебные акты). |
| **Судебный акт** | `judicialActDate` | Дата акта, которым подтверждено требование. |
| **Исполнительное производство** | `hasEnforcementProceedings` | Возбуждённое приставами взыскание. При введении процедуры прекращается. |
| **Доверенность** | `powerOfAttorneyNumber`, `powerOfAttorneyDate` | Доверенность от должника юристу. |
| **Спецсчёт** | `procedureInitiationSpecialAccountNumber` | Специальный банковский счёт должника в процедуре, открывает финуправляющий. |
| **Номер дела** | `caseNumber` | Номер арбитражного дела, вида `А40-123456/2025`. |

## Персональные данные должника

| Термин | В коде | Пояснение |
|---|---|---|
| **СНИЛС** | `snils` | Страховой номер индивидуального лицевого счёта, 11 цифр. Уникален в таблице. |
| **ИНН** | `inn`, `employerInn` | Идентификационный номер налогоплательщика: 12 цифр у физлица, 10 у организации. |
| **ОГРН** | `aauOgrn` | Основной государственный регистрационный номер организации. |
| **Паспорт** | `passportSeries`, `passportNumber`, `passportIssuedBy`, `passportIssuedDate`, `passportDepartmentCode` | Серия, номер, кем и когда выдан, код подразделения. |
| **Место жительства / регистрация** | `actualPlaceResidence` и группа `registration*` | Фактический адрес одной строкой и адрес регистрации, разобранный на регион, район, город, населённый пункт, улицу, дом, корпус, квартиру. |
| **Семейное положение** | `maritalStatus`, `spouseFullName`, `spouseBirthDate`, `marriageTerminationDate` | Влияет на формулировки в документах и на состав имущества. |
| **Несовершеннолетние дети** | `hasMinorChildren`, `children` (JSON) | Иждивенцы; учитываются при определении прожиточного минимума. |
| **Смена фамилии** | `isLastNameChanged`, `changedLastName` | Прежняя фамилия указывается в публикациях и запросах. |

### Родительный падеж (`*Genitive`)

Поля `firstNameGenitive`, `lastNameGenitive`, `middleNameGenitive`,
`spouseFullNameGenitive`, `fioGenitive` хранят **ФИО в родительном падеже**
(«Иванова Ивана Ивановича»). Русские юридические документы требуют склонения
(«заявление Иванова И. И.», «в отношении Иванова Ивана Ивановича»), а
автоматическое склонение ненадёжно, поэтому падежная форма вводится вручную и
подставляется в шаблоны как есть. Не пытайся выводить её из именительного падежа.

## Синтаксис шаблонов документов

Шаблоны — загруженные `.docx` / `.xlsx` файлы (`DocumentTemplate`), обработчик —
`DocumentTemplateProcessor`.

| Конструкция | Пример | Что делает |
|---|---|---|
| Путь к данным | `{{ court.name }}`, `{{ financialManager.fioGenitive }}` | Точечная нотация от `Contracts`, разрешается `EntityDataResolver` через `PropertyAccessor`. Отсутствующее значение подставляется пустой строкой. |
| Функция | `{{ ТЕКУЩАЯ_ДАТА('дд.ММ.гггг') }}` | Обрабатывается `CustomFunction`. Имена функций — заглавными кириллицей. Маски даты: `дд`, `ММ`, `ММММ` (месяц словом), `гггг`, `гг`. |
| Блок `FOR` | список кредиторов, список требований | Повтор секции по коллекции. |
| Метод-формулировка | `maritalStatusDescription`, `startNotificationText` | Статические методы `PreCourtMethods` и `ProcedureInitiationMethods`, собирающие готовый текст с учётом пола, семейного положения и склонений. |

Месяцы в документах часто нужны в родительном падеже («15 января 2025 г.») —
для этого есть `DateHelperService::getMonthNameGenitive()`.

## Роли пользователей

| Роль | Кто это |
|---|---|
| `ROLE_ADMIN` | Администратор системы. Доступ к `/api/doc`. |
| `ROLE_FINANCIAL_MANAGER` | Финансовый управляющий. |
| `ROLE_MANAGER` | Менеджер / юрист, ведущий дела. |
| `ROLE_USER` | Базовая роль, выдаётся всем автоматически. |

Иерархия: `ROLE_ADMIN` -> `ROLE_FINANCIAL_MANAGER` -> `ROLE_MANAGER` -> `ROLE_USER`.
